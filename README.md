# Liquara

Cash intelligence connected to the heart of your business.

- `index.html` – the website (landing page, pricing, FAQ)
- `app.html` – the Liquara web app (laptop, phone, any browser)
- Android app – built automatically by `.github/workflows/apk.yml` and published under Releases
- `liquara-helper.js` – the Cloudflare Worker for in-app payments (Stripe embedded checkout), license unlock, AI reading and the savings finder
- `config.js` – put the helper address and Stripe publishable key here
- `setup-keys.html` – makes the license key pair, in your browser only
